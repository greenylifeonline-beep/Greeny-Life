# Canonical Weight-Merge selective integration

The useful donor value was extracted into the existing V9 Model Lab instead of resurrecting Weight-Merge-Lab. Canonical V9 now supports an explicit-authority, local CPU LINEAR merge with deterministic input hashing and a receipt. Its default behavior remains refusal/dry-run. MergeKit is discovered if already installed and is never downloaded automatically.

The donor's registries, compatibility layer, domain wrappers, and state machine are subsumed by existing V9 components. The CLI is now a thin canonical entrypoint. Tests use only tiny synthetic tensors.

After the canonical commit is remote-bound, the clean donor directory is physically deletion-eligible. Recovery remains available from Git commit 39493ccbace7a922790737f4e0befa85239927be.
