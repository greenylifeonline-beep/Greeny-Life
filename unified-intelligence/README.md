## Responsibilities

### Brain
Central orchestration and decision coordination.

### Intelligence
All analytical and operational intelligence capabilities:
- audit
- cleanup
- duplicate detection
- integrity
- scanning
- validation
- analysis
- registry

### GL-DOS
Governance and control:
- integrity
- policies
- guardrails
- validation gates
- execution controls
- change authorization

### Memory
Persistent project and runtime context.

### Knowledge
Structured reference knowledge:
- schemas
- taxonomy
- references
- project metadata

### Master Data
Canonical source of truth.

No legacy dataset may override Master Data.

### Reports
Traceable outputs generated from executions.

Reports are derived artifacts and never sources of truth.

## Migration Principle

Existing systems are not deleted during the foundation phase.

The migration proceeds through:

1. Inventory
2. Dependency analysis
3. Capability mapping
4. Adapter creation
5. Unified registry
6. Unified orchestration
7. Validation
8. Parallel execution
9. Cutover
10. Legacy retirement

Destructive deletion is permitted only after successful validation and explicit cutover.
