# Commercial Change Governance

Price, supplier, shipment, and offer changes are kept as time-bound proposals in the `CommercialChange` ledger. MasterMind reads only pending changes attached to the requested product and displays them in the decision package.

No ledger record changes a price, supplier, offer, shipment, contract, invoice, payment, or customs record by itself. Critical pending changes block the package; all other pending changes require explicit user approval before controlled execution can be considered.
